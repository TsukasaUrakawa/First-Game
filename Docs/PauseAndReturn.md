# 中断とタイトルへの復帰

プレイ中の右上に「中断」を置いています。部屋・拡大中の棚だけでなく、
本一覧・取り出し確認・完成図を見ている途中でも開けます。
生成りの紙と緑のボタンで、既存の画面に見た目を揃えています。

- 「遊びに戻る」は、元の画面と選択を保って中断画面だけを閉じます。
  手持ちの選択、棚の選択、カメラ、本一覧の絞り込み・スクロール・選択、
  取り出し確認、完成図、案内の進み具合を維持します。
- 「保存してタイトルへ」は、手持ちの順番、置いた本の位置、完成済みの棚を
  保存してからタイトルへ戻ります。不正解の並びもそのまま保存します。
  「続きから」で再開すると部屋から始まり、同じ本棚と手持ちが戻ります。
- 一覧で選んだだけで、まだ取り出していない本は箱に残ります。
  一時的な確認画面や棚の選択、拡大位置、絞り込みはセーブに含めません。
  本の移動がまだない場合は、タイトルに「はじめる」を表示します。
- 保存できなければ中断画面に案内を出し、ゲームを移動しません。
  再度保存を試すか、「遊びに戻る」で続行できます。

部屋でEscapeを押しても中断画面を開けます。中断中のEscapeは「遊びに戻る」です。
本一覧・確認画面・完成図・棚の拡大では、これまでどおり手前の表示を先に戻します。
設定画面を開いている間とクリア後は、中断ボタンを隠します。

## 処理と編集場所

`ShelfCare`の`PauseMenu`に`PauseMenuController`があります。
Canvas直下の`OpenPauseButton`が入口、`PausePanel/PauseCard`が中断画面です。
初期表示は非表示で、「遊びに戻る」にキーボードフォーカスを置きます。

中断時はTime.timeScaleを0にし、閉じると開く前の値に戻します。
ゲーム側の入力ガードに加え、背後のSelectableとScrollRectを無効にするため、
キーボード移動やスクロールの慣性も背後の画面に作用しません。
復帰時は元の有効状態を戻し、選択中の棚の本を選び直す必要はありません。
開閉時だけUIを走査し、毎フレームの検索は追加していません。
案内と強調表示は中断中だけ隠します。BGMは音量・ミュート設定に従って再生を続けます。

`GameplayUIController`の`PauseChanged`は、案内の表示とHUDを更新します。
通常の`StateChanged`と分けることで、一時的な開閉で棚の選択を解除しません。
箱が開く途中で中断した場合は開閉をキャンセルし、戻ってから再び箱を開けます。

タイトルへの移動では`GameProgressController.SaveNow()`と設定の保存を確認し、
成功した場合だけ両ボタンを無効にします。クリック音を実時間で待ってから時計を戻し、
既存の`SceneButtonController.LoadTitleScene()`で移動します。
連打と移動中のEscapeを拒否し、二重移動を防ぎます。
シーン終了やEditorのPlay停止時にも時計を戻します。

セーブのバージョンとキーは変更していません。`Docs/SaveAndContinue.md`も参照してください。
確認方法は`Tests/README.md`にまとめています。ブラウザでの保存完了と再読み込みは、
unityroom向けWebGLビルドで別途確認します。
