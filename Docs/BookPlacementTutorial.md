# 本を取り出して配置するチュートリアル

初回プレイでは「あそびかた」を自動表示し、実際の操作に合わせて案内を
切り替えます。案内はゲーム全体を止めず、操作対象と案内文を明るく残して
周囲を暗くします。段ボール本体や操作するボタン・本の画像が緑色にゆっくり
点滅します。囲み枠や長方形の塗りは表示しません。空の配置場所は周囲を暗く
して示します。強調表示はクリックを妨げません。

1. 左下の箱を開く。
2. 本一覧から本を選ぶ（最大9冊）。
3. 「選んだ本を確認」を押す。
4. 選んだ本を確かめて取り出す。
5. 手持ちから置く本を選ぶ。
6. 本と同じ色の棚を拡大する。
7. 空いている場所に本を置く。

実際に本を置けた時点で案内を完了します。この段階では正解の並びを教えず、
完成図を見ながら並べる遊びに繋げます。別の棚を開いた場合や、選択を解除した
場合、一覧や完成図を開いた場合にも、現在の状態に合わせて案内を戻します。

案内の「スキップ」で閉じると、以後は自動表示しません。部屋または棚の
拡大画面の右上にある「あそびかた」から再表示できます。再表示しても、
手持ち・配置した本・カメラはリセットせず、現在の状態から案内します。
ゲームクリア後は案内と再表示ボタンを隠します。

## 編集と保存

- シーンの`TutorialLayer`に案内パネル・再表示ボタン・暗幕をまとめています。
- `BookPlacementTutorial`が画面・選択・手持ちの変更と配置成功を受け取り、
  案内内容を更新します。毎フレーム更新するのは強調表示の追従位置と点滅です。
- `TutorialSpotlightGraphic`は操作対象の周囲だけを暗くし、境界をぼかします。
  `TutorialFocusEffect`は1.8秒周期の滑らかな点滅と段ボールの色を制御します。
  材質アセットを変更せず、対象が変わる・スキップ・完了・無効化で元の色に戻します。
- 初回表示の記録はPlayerPrefsの`ShelfCare.BookPlacementTutorial.v1`です。
  スキップまたは配置成功で1を保存します。セーブデータや本の配置とは独立です。
- 文言を増やすときは`Assets/Fonts/BookList/Characters.txt`にも追加し、
  `Tools/BuildBookListFont.cs`で日本語フォントを再生成してください。

テスト方法と記録の扱いは`Tests/README.md`を参照してください。
