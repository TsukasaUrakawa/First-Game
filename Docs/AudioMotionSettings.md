# 音量と画面の動きの設定

タイトルと、ゲーム中の部屋・棚の右上に「設定」を置いています。
生成りの紙と緑の操作部で、既存の画面と見た目を揃えています。

- BGMと効果音を別々に0〜100%で調整できます。変更はすぐに反映します。
- 「効果音を試す」で、既存のボタン音を確認できます。
- 「音をミュート」は両方を消音します。解除すると選んだ音量に戻ります。
  BGMの再生自体は止めず、消音中も再生位置は進みます。
- 「画面の動きを控えめに」は、背景の揺れ・視差、見出しと装飾の動き、
  確認画面の拡縮を止めます。案内対象と選択中の本は点滅を止め、緑色を残します。
  本の配置操作やカメラの移動は引き続き使えます。
- 「閉じる」またはEscapeで設定だけを閉じます。棚の拡大位置、手持ち、
  配置した本、チュートリアルの進み具合は維持します。

本一覧・完成図・クリア画面では設定ボタンを隠します。
タイトルの「はじめから」確認中やシーン移動中にも設定を開けません。
設定中は背後の操作を止め、チュートリアルと強調表示は一時的に隠します。
再開すると同じ状態に戻ります。
プレイを途中でやめる場合は、設定を閉じて右上の「中断」を使います。
保存してタイトルへ戻る流れは`Docs/PauseAndReturn.md`を参照してください。

## 保存

初期値はBGM・効果音とも100%、ミュートなし、通常の動きです。
音量はシーンに設定された元の音量に掛ける倍率なので、既存の音量バランスを保ちます。

`GamePreferences`がPlayerPrefsの`ShelfCare.Settings.v1`にJSONを保存します。
進行・初回案内の記録とは別のキーで、「はじめから」やリプレイでも設定を保ちます。
無効なバージョン・範囲外の値・壊れたデータは初期値で読み、操作するまで上書きしません。

スライダー操作中は即時反映し、最後の変更から実時間で0.35秒後に保存します。
閉じる・フォーカスを失う・一時停止・終了時にも未保存の変更を保存します。
保存できない場合は画面に表示し、次の変更や閉じる操作で再試行します。
ブラウザでの保存先はそのブラウザの環境に依存し、端末間で共有しません。

## 編集する場所

- 両シーンの`SceneSettings`に`SettingsPanelController`と`SceneAudioSettings`があります。
  表示はCanvas直下の`SettingsPanel/SettingsCard`、入口は`OpenSettingsButton`です。
- 音量スライダーの行は48、つまみは上下2ずつ空けた44の高さです。
  Sliderがつまみの縦アンカーを0〜1へ変更するため、つまみの`sizeDelta.y`は-4にします。
  正の44を指定すると行の高さが加算され、92まで伸びて下のボタンに重なります。
  試聴ボタンは効果音の行から36、ミュートの行から40の間隔を空けています。
- `SceneAudioSettings`はシーン内のAudioSourceの元の音量・ミュート状態を記録します。
  `_musicSources`にはタイトルの`TitleBGM`、ゲームの`GameBGM`だけを登録し、
  それ以外の音源に効果音の倍率を適用します。
  無効なオブジェクト上の音源と、他のAwakeで追加された音源も初期化時に取得します。
  毎フレームの音源検索は行いません。将来プレイ途中に音源を生成する場合は、
  登録処理を追加してください。
- 同じコンポーネントの`_effectsSource`・`_clickSound`・`_clickVolume`で通常の
  クリック音をまとめています。設定の開閉、色フィルター、棚の選択解除、
  タイトルの新規開始キャンセルに使います。設定のトグルは値を反映した後に鳴らすので、
  ミュート中は消音され、解除時は選んだ効果音の音量で鳴ります。
  スライダーの連続操作では鳴らさず、「効果音を試す」で聞き比べられます。
- 本の選択・取り出し・配置・返却などの既存音はそのまま使います。
  通常クリック音を重ねて登録しないようにしてください。
  クリア画面は`SceneButtonController`の`LoadTitleSceneWithSound`と
  `LoadGameSceneWithSound`から、短いクリック音の終了後にシーンを切り替えます。
  待機は実時間で行い、移動中は両ボタンを無効にして連打による二重移動を防ぎます。
- `PresentationMotion`と`AmbientGeometryGraphic`は設定変更を受け取り、
  控えめな演出では基準位置を表示します。静止中は文字・装飾の毎フレームの再描画を省きます。
- `TutorialFocusEffect`と`ShelfBookMoveController`は控えめな演出では一定の緑色を使います。
  `BookPopUpController`は確認画面を等倍・不透明で表示します。
- 日本語を追加する際は`Assets/Fonts/BookList/Characters.txt`にも追加し、
  `Tools/BuildBookListFont.cs`で静的アトラスを再生成してください。

設定の保存・入力・表示・既存操作の検証手順は`Tests/README.md`を参照してください。
WebGLでの実際の音の聞き分け、ブラウザ再読み込み後の保存、Escapeとポインター操作は
公開用ビルドで別途確認します。
