# 棚の本の移動・入れ替え

棚に置いた本をクリックすると、その本を選択します。部屋からクリックした場合は、その本の棚を拡大します。
選んだ本自体を穏やかな緑色で点滅させ、上部の操作欄に背表紙のプレビューと操作案内を表示します。
幾何学模様の画像と本の正解位置は変更しません。

- 同じ棚の空いている場所をクリックすると移動します。移動先には従来と同じ半透明の配置プレビューが出ます。
- 同じ棚の別の本をクリックすると、2冊の位置を入れ替えます。
- 同じ本をもう一度クリック、「選択解除」、右クリック、Escで選択を解除します。
  選択中の右クリックはUI上でも解除します。選択がない場合は従来どおり、UI外の右クリックで部屋へ戻ります。
- 上部の「手持ちに戻す」で選択した本を手持ちの最後に戻します。9冊持っている間は
  このボタンに「手持ちがいっぱい」と表示して無効にします。棚の中での移動・入れ替えは可能です。
- 手持ちの本を選ぶと棚の本の選択を解除し、棚の本を選ぶと手持ちの選択を解除します。
- 「部屋に戻る」は選択中でも1回で部屋へ戻ります。Esc・右クリックはまず選択だけを解除します。
- 本一覧、完成図、別の棚、部屋への移動、あそびかたの再表示、ゲームクリアで選択を解除します。
- 完成済みの棚、ロックされた本・位置、別の色の棚への移動はできません。
  並べ直しただけでは完成判定せず、従来どおり「並びをチェック」で完成を確定します。

## 実装と保存

`ShelfBookMoveController`が棚の本の選択と2回のクリックを管理します。`BookVisual3D`がMeshRendererの
MaterialPropertyBlockで選択中の本だけを緑色にし、解除・移動・シーン終了時に元へ戻します。
共有マテリアルや元の画像は変更しません。点滅にはunscaled timeを使用し、枠や新しい材質は生成しません。
`ShelfBookMoveUI`がイベントに応じて通常の操作欄と移動用の操作欄、プレビュー、返却可否を更新します。

`BookSlot.TryMoveOrSwapTo`は、2冊の参照・位置・クリック先・コライダーを両方とも更新してから、
棚の変更を1回だけ通知します。既存の本を移動するため、手持ちや本の生成・破棄を経由せず、
本の正解位置と大きさを保ちます。通知を受けたその時点で保存・判定しても中間状態を見せません。

自動保存は従来の棚の変更通知を使用し、保存形式のバージョンは1のままです。
移動・交換後の配置を記録し、再開時には選択を解除して部屋に戻します。
保存済みの進行とチュートリアルの既読記録をそのまま利用できます。

## 編集と確認

- `ShelfCare`の`UIManager`にある`ShelfBookMoveController`と`ShelfBookMoveUI`に参照をまとめています。
- `ShelfActionPanel/ShelfNormalActions`が従来の操作、`ShelfMoveActions`が選択中の操作です。
  同じ場所で切り替え、棚の本や手持ちを覆いません。
- 「部屋に戻る」の既存のクリック音は保ち、移動先は`GhostBook3D`の半透明メッシュで表示します。
- 検証の準備・元の保存の退避と復元は`Tests/README.md`を参照してください。
  WebGLでのOS入力やブラウザ上の描画・保存は別途確認が必要です。
