# 手持ちの本と9冊の上限

手持ちは画面下部の9枠に表示します。空の状態でも枠と操作案内を表示し、
箱から本を取り出すと冊数と画像を更新します。本をクリックすると緑の枠と
「選択中」を表示し、もう一度クリックすると選択を解除します。

選んだ本は、同じ色の棚の空いている場所をクリックすると配置できます。
配置後は残りの本を左に詰め、選択を解除します。棚から戻した本は手持ちの
最後に追加します。手持ちが9冊のときは、追加選択・取り出し・棚からの
返却を制限します。

本一覧の選択上限は手持ちの空き枠に従います。たとえば2冊持っている場合は
7冊まで選べます。取り出す前の確認画面には最大9冊を表示し、冊数に応じて
カード幅を調整します。

## 編集箇所

- 上限の基準は`HandItemController.MaxCapacity`です。上限を変更するときは
  シーンの手持ち枠と確認画面の参照配列も同じ数に揃えてください。
- 手持ちの外観は`HandItemPanel`、並びはその子の`HandBookRow`で編集します。
- `HandInventoryUI`が冊数・選択状態・操作案内をイベントで更新します。
  `HandItemSlotUI`は各枠の画像・番号・空き表示・選択枠を担当します。
- 本一覧や完成図を開いた間、手持ちは`GameplayUIController`が非表示にし、
  背面の枠を選べないようにします。
