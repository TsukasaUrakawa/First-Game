# 本一覧の色別フィルター

本一覧の上部に「すべて」と8色のボタンを表示します。色を選ぶと同じ色の本だけを表示し、
各ボタンには箱に残っている冊数を表示します。残り冊数には、まだ取り出していない選択中の本も含みます。
手持ち・配置済みの本は箱の冊数に含めません。

色を切り替えても選択済みの本と選んだ順番を保ちます。画面に見えていない選択がある場合は下部に案内し、
確認画面にはすべての色の選択をまとめて表示します。選択上限は色ごとではなく手持ちの空きを含む全体の9冊です。
「選択をクリア」は、ほかの色で選んだ本も解除します。閉じる操作による選択解除は従来と同じです。

色を変えるとスクロールの慣性を止めて先頭に戻します。同じ色を開き直す場合はカードの並びを保ち、
一覧を閉じて再度開いた場合も最後のフィルターを維持します。ゲームの新規開始・再開では「すべて」に戻します。
確認画面を開いている間は背面のフィルターを操作できません。

その色の本が残っていない場合は、別の色・「すべて」を選ぶ案内を表示します。
箱全体が空の場合は専用の説明を表示します。手持ちがいっぱいでも、色を切り替えて一覧を確認できます。

## 実装

- `BookListUI`が生成したカードを保持し、色に応じて表示を切り替えます。切り替えるたびに生成・並べ替えは行いません。
  取り出し時はカードをキャッシュとレイアウトからすぐに外し、Destroyの完了前でも冊数に反映します。
- 冊数は本のカタログから取り出し・復元済みの識別名を除いて計算し、内容の変更時に更新します。
  `GameProgressController`の既存の復元処理から、最初に一覧を開く前でも正しい冊数を取得できます。
- `BookColorFilterUI`が色・冊数・選択中マーカー・空の説明を更新します。
  `BookListControls`が他色の選択や空の一覧に応じた操作案内を表示します。毎フレームの再検索は行いません。
- フィルターで一時的に隠したカードは選択を保ち、ホバーの色だけを戻します。
  非表示のカードの選択コールバックと、確認中のフィルター変更にはガードを入れています。
- フィルターと未確定の選択は進行の保存には追加しません。取り出した本は従来どおり自動保存します。

## 編集と検証

`ShelfCare`の`BookListPanel/BookColorFilters`が9つのボタン、`BoxRemainingCount`が箱全体の冊数です。
各ボタンは`BookColorFilter0`（すべて）、`BookColorFilter1`から`8`（緑・青・ベージュ・赤・紫・茶・白・黒）の順です。
色の帯、色名、冊数と「選択中」の文字で現在の状態を示します。
`Scroll View/Viewport/BookFilterEmptyState`に空の場合の説明があります。

タイトル・確認画面・紙のカードと同じ日本語フォントとRoundedPanelGraphicを使用します。
文言の追加時は`Assets/Fonts/BookList/Characters.txt`も更新してください。
テストと保存記録の退避・復元方法は`Tests/README.md`を参照してください。
