# 棚選択と本の確認画面

左の棚ボタンは、実際の本棚と同じ2列×4段の並びです。色名と収納冊数を
表示し、クリック1回で該当する棚を拡大します。冊数は正解数ではなく、
現在置かれている本の数です。並びをチェックして正解になると「完成」に
変わります。

拡大中は画面上部に棚名・収納冊数・「完成図を見る」「並びをチェック」を
固定表示します。チェック後も拡大画面を保つため、そのまま並べ直せます。
本一覧や完成図を閉じると、元の棚と操作バーに戻ります。左上のClose、
Escape、UIの外での右クリックで部屋に戻ります。

本の確認画面は選択した冊数だけプレビューを中央に並べ、受け取り後の
手持ち冊数を表示します。「選び直す」またはEscapeでは選択を残したまま
本一覧に戻ります。本一覧自体を閉じると選択を解除します。

## 編集時の対応

- 棚ボタンの共通レイアウトは`BookShelfButtonPrefab`、並びはシーン内の
  `ShelfCardGrid`で編集します。色名・本棚・色帯は各インスタンスの設定です。
- 拡大中の操作バーは`ShelfActionPanel`、確認画面は
  `BookPopUp/BookConfirmationCard`です。冊数に応じたプレビューの整列には
  `HorizontalLayoutGroup`を使います。
- `RoundedPanelGraphic`は角丸背景を描画します。角丸半径と色をInspectorで
  変更でき、画像素材を追加する必要はありません。
- 棚の収納・完成表示は`BookShelfJudge.StateChanged`で更新します。
  `BookSlot`が配置・返却を通知するため、毎フレームの探索は行いません。
- 日本語文言を増やす場合は`Assets/Fonts/BookList/Characters.txt`にも追記し、
  Editモードで`Tools/BuildBookListFont.cs`をUnity CLIから実行してフォントを
  再生成します。

操作テストの実行方法は`Tests/README.md`を参照してください。
